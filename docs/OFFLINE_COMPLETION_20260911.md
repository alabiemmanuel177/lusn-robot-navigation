## Decisions that cannot be honestly marked complete

`configs/physical_experiment_design_draft_v2.yaml` deliberately does not invent
approved primary contrast, multiplicity rule, target effect/power, nuisance
parameters, confirmatory seed count or inference method. The proposal is an
equal-world-weight paired ordered-completion comparison with explicit unknown
bounds; six held-out world reservations limit independent-cluster precision.
These require design approval and, for nuisance estimates, non-protected evidence.
Implementing the tooling does not approve those scientific choices.

The original ambiguous-reference variant is preserved and described narrowly as
underspecified attribute in a single-anchor scene. It is not a test of choosing
between competing chairs. Adding distractor chairs or broadening that claim would
be a separate design change, not an undocumented offline cleanup.
