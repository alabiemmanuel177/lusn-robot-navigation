# Durable findings from Steps 1–4 investigation

- OWLv2 original run uses module PROMPTS insertion order, while the short-prompt
  probe uses serialized JSON plan order (write sorts keys). Never infer raw-logit
  column identities from an arbitrary dictionary reload. Pin an explicit ordered
  query list and reconstruct each saved emitted label. Initial cross-panel report
  was corrected in a create-once v2 audit; original arrays remain intact.
- `verify_against_depth().verified` can pass with floor-height evidence only.
  Require explicit x/y/height observability before claiming all-axis translation
  consistency; that still is not independent six-DOF pose validation.
- Nominal published optical TF and actual render-camera mounts differ by about
  0.13709 m in this setup. Composition through the base frame is a candidate
  correction; matching the command numerically does not prove actual robot pose.
- Short prompts failed to restore doorway proposals in the fixed development
  panel. Do not lower confidence thresholds or stretch scores to meet quotas.
